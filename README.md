# 📊 Dalty Grades — نظام إدارة درجات الطلاب

> تطبيق ويب متكامل لإدارة درجات الطلاب والغياب والجداول الدراسية، يعمل بالكامل داخل المتصفح دون الحاجة إلى خادم. يدعم العمل أوفلاين (PWA) ومزامنة السحابة عبر Firebase.

---

## 🚀 الميزات الرئيسية

### 📝 إدارة الدرجات
- جدول درجات تفاعلي لكل فصل دراسي
- إضافة أعمدة مخصصة (أعمال يومية، اختبارات، نشاط، ...) بأوزان قابلة للتعديل
- حساب المجموع والمتوسط تلقائياً
- تلوين الدرجات بناءً على مستوى الطالب
- دعم إدخال الغياب (غياب / عذر) مباشرةً من جدول الدرجات

### 🎯 الراصد الأسبوعي (Numpad)
- لوحة إدخال رقمي سريعة لرصد الدرجات دون لوحة المفاتيح
- إدخال صوتي بالعربية (يعمل أوفلاين بنموذج Whisper المحلي)
- توزيع ذكي تلقائي للدرجات
- عرض كروت الطلاب مع الصور وإحصائيات لحظية

### 🗂️ إدارة الفصول والطلاب
- إنشاء فصول دراسية متعددة وإدارتها
- إضافة الطلاب مع صورهم الشخصية
- تعديل وحذف بيانات الطلاب
- دعم نظام **القاموس التلقائي** للتعرف على أسماء الطلاب

### 📅 جدول الغياب
- تسجيل الغياب أسبوعياً لكل فصل (الأسبوع 1 → 32)
- إحصاءات فورية: عدد الغائبين، الحضور، المعذورين
- ربط الغياب تلقائياً مع صفحة الدرجات

### 🗓️ الجدول الدراسي
- إنشاء جدول أسبوعي بالحصص والأيام مع أوقات دقيقة
- مؤشرات الطابور والفسحة وألوان مميزة لكل فصل
- تصدير الجدول كصورة
- ربط تلقائي بالصفحة الرئيسية لعرض الحصة الحالية

### 📤 التصدير والتقارير
- تصدير الدرجات إلى **Excel (.xlsx)**
- كشف درجات رسمي للطباعة (A4 مع رأس المدرسة)
- كشف التفريغ المبسّط
- كشف توقيع المتابع
- تصدير الكروت والجداول كـ **صور (PNG)**
- صفحة مشاركة الدرجات مع الطلاب (grades-viewer)

### 📖 توزيع المنهج
- خريطة توزيع الوحدات والدروس على أسابيع الترم
- تمييز أسابيع الاختبارات والعطلات
- ودجت في الصفحة الرئيسية يعرض الأسبوع والدرس الحالي

### 🔔 نظام الإشعارات والمنبّه
- تنبيهات مخصصة مرتبطة بأيام وأوقات محددة
- 6 نغمات منبّه جاهزة + دعم رفع نغمة خاصة
- مركز إشعارات مع شارة العدد

### ☁️ المزامنة السحابية (Firebase)
- تسجيل الدخول بحساب Google
- مزامنة البيانات عبر Firebase Realtime Database
- كل مستخدم بيانات مستقلة وآمنة
- لوحة إدارة الاشتراكات (`admin-subscriptions.html`)

### ⚙️ إعدادات متقدمة
- تغيير الخط وحجمه لكل قسم بشكل مستقل
- إعدادات القاموس ونسبة التطابق وكلمة الفاصل
- حفظ جميع الإعدادات تلقائياً (LocalStorage)

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| HTML5 / CSS3 | هيكل التطبيق وتصميمه الكامل |
| JavaScript (Vanilla) | منطق التطبيق — مقسّم على 11 ملف |
| [SheetJS (xlsx)](https://sheetjs.com/) | تصدير ملفات Excel |
| Firebase Auth + Realtime DB | المزامنة السحابية وتسجيل الدخول |
| Google Fonts — Cairo | الخط العربي الرئيسي |
| LocalStorage API | حفظ البيانات محلياً |
| Service Worker | دعم العمل أوفلاين (PWA) |
| Web App Manifest | تثبيت التطبيق على الجهاز |
| Web Speech API + Whisper | الإدخال الصوتي (أونلاين + أوفلاين) |

## 🖥️ طريقة الاستخدام

### التشغيل السريع
1. افتح ملف `index.html` في أي متصفح حديث (Chrome, Edge, Firefox, Safari).
2. سجّل الدخول بحساب Google أو استخدم التطبيق محلياً بدون تسجيل.
3. ابدأ بإنشاء **فصلك الدراسي الأول** من الشريط الجانبي.

> ⚠️ لتفعيل الإدخال الصوتي أوفلاين وService Worker، يجب تشغيل التطبيق عبر `localhost` أو `HTTPS` — راجع `docs/SETUP.md` للتفاصيل.

### الصفحات الرئيسية

| 🏠 الرئيسية | لوحة التحكم، الحصة الحالية، مؤشر اليوم الدراسي |
| 📝 الدرجات | إدخال وعرض درجات الطلاب |
| 🎯 الراصد | رصد سريع بلوحة أرقام وإدخال صوتي |
| 🗓 الجدول | بناء الجدول الدراسي الأسبوعي |

| 🤒 المرضى | متابعة الطلاب المرضى |
| 🎤 الإملاء | رصد درجات الإملاء بالصوت |

| 📖 توزيع المنهج | خريطة الوحدات والدروس |

### التنقل
- **شريط أيقونات سفلي (الدوك):** للصفحات الأكثر استخداماً
- **القائمة الجانبية (☰):** للوصول لجميع الصفحات
- **شريط المساعدة:** في القائمة الجانبية → قسم المساعد

## 💾 البيانات والحفظ

- تُحفظ البيانات **تلقائياً** في `localStorage` بالمتصفح
- عند تسجيل الدخول بـ Google، تُزامَن البيانات مع **Firebase**
- يُنصح بالتصدير الدوري إلى Excel كنسخة احتياطية إضافية
- مسح بيانات المتصفح يحذف البيانات المحلية (السحابية محفوظة)

## 👨‍💻 التطوير والتخصيص

### تغيير الألوان
ابحث في `style.css` عن قسم `:root` وعدّل متغيرات CSS.

### إضافة صفحة جديدة
1. أضف زر في القائمة الجانبية وشريط الدوك في `index.html`
2. أضف `<div class="page" id="page_NEW">` في قسم الصفحات
3. أنشئ ملف `js/app-XX-newpage.js` وأضفه في نهاية `index.html`

### تعديل الدرجات والأعمدة
من واجهة التطبيق مباشرةً ← زر "الأعمدة" في صفحة الدرجات.

### ملفات JS — الترتيب مهم
الملفات تُحمَّل بترتيب محدد في `index.html`؛ `app-01-core.js` يُهيّئ الحالة العامة قبل باقي الملفات.

## 🔧 إعداد Firebase (للمزامنة السحابية)

1. أنشئ مشروع على [Firebase Console](https://console.firebase.google.com)
2. فعّل **Authentication → Google**
3. فعّل **Realtime Database**
4. انسخ إعدادات المشروع (firebaseConfig) إلى `auth.js`
5. انشر قواعد الأمان من `firestore.rules`

> التفاصيل الكاملة في `docs/SETUP.md`
