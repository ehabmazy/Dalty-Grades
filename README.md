# 📊 Dalty Grades — نظام إدارة درجات الطلاب

> تطبيق ويب متكامل لإدارة درجات الطلاب والغياب والجداول الدراسية، يعمل بالكامل داخل ملف HTML واحد دون الحاجة إلى خادم أو اتصال بالإنترنت.

---

## 🚀 الميزات الرئيسية

### 📝 إدارة الدرجات
- جدول درجات تفاعلي لكل فصل دراسي
- إضافة أعمدة مخصصة (أعمال يومية، اختبارات، نشاط، ...) بأوزان قابلة للتعديل
- حساب المجموع والمتوسط تلقائياً
- تلوين الدرجات بناءً على مستوى الطالب
- دعم إدخال الغياب (غياب / عذر) مباشرةً من جدول الدرجات

### 🗂️ إدارة الفصول والطلاب
- إنشاء فصول دراسية متعددة وإدارتها
- إضافة الطلاب مع صورهم الشخصية
- تعديل وحذف بيانات الطلاب
- دعم نظام **القاموس التلقائي** للتعرف على أسماء الطلاب عند إدخالها

### 📅 جدول الغياب
- تسجيل الغياب أسبوعياً لكل فصل
- تصفح الغياب بالأسابيع (الأسبوع 1 → 32)
- إحصاءات فورية: عدد الغائبين، الحضور، المعذورين
- ربط الغياب تلقائياً مع صفحة الدرجات

### 🗓️ الجدول الدراسي
- إنشاء جدول أسبوعي بالحصص والأيام
- تحديد أوقات كل حصة مع مؤشرات الطابور والفسحة
- ألوان مميزة لكل فصل في الجدول
- تصدير الجدول كصورة

### 🃏 بطاقات الطلاب
- عرض بطاقة لكل طالب تتضمن: الصورة، الاسم، الدرجات، الغياب
- دعم عرض أحادي وعرض شبكي
- إعدادات تخصيص كاملة للبطاقة

### 📤 تصدير البيانات
- تصدير الدرجات إلى **Excel (.xlsx)**
- تصدير الجداول والبطاقات كـ **صور (PNG)**
- نسخ بيانات الغياب والإملاء بنقرة واحدة

### ⚙️ إعدادات متقدمة
- تغيير الخط وحجمه لكل قسم (جدول الدرجات، التفريغ، البطاقات)
- التحكم في أعمدة الغياب الظاهرة
- إعدادات نسبة تطابق القاموس وكلمة الفاصل
- حفظ جميع الإعدادات تلقائياً في المتصفح (LocalStorage)

---

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| HTML5 / CSS3 | هيكل التطبيق وتصميمه الكامل |
| JavaScript (Vanilla) | منطق التطبيق بالكامل |
| [SheetJS (xlsx)](https://sheetjs.com/) | تصدير ملفات Excel |
| Google Fonts — Cairo | الخط العربي |
| LocalStorage API | حفظ البيانات محلياً في المتصفح |
| Web App Manifest | دعم تثبيت التطبيق على الجهاز (PWA) |

## 🖥️ طريقة الاستخدام

### التشغيل
1. افتح ملف `index.html` في أي متصفح حديث (Chrome, Edge, Firefox, Safari).
2. أدخل **اسم المستخدم وكلمة المرور** في شاشة تسجيل الدخول.
3. ابدأ بإنشاء **فصلك الدراسي الأول** من الشريط الجانبي.

### الصفحات الرئيسية
- **الدرجات** — إدخال وعرض درجات الطلاب
- **الغياب** — تسجيل الغياب الأسبوعي
- **الجدول** — بناء الجدول الدراسي الأسبوعي
- **البطاقات** — عرض بطاقات الطلاب

### التنقل
استخدم **القائمة الجانبية** (زر ☰) للتنقل بين الصفحات.

---

## 💾 البيانات والحفظ

- تُحفظ جميع البيانات **تلقائياً** في `localStorage` بالمتصفح.
- لا توجد قاعدة بيانات خارجية أو خادم.
- عند مسح بيانات المتصفح، **ستُحذف بيانات التطبيق**.
- يُنصح بتصدير البيانات إلى Excel بانتظام كنسخة احتياطية.

---

## 📋 المتطلبات

- متصفح حديث يدعم:
  - `localStorage`
  - `CSS Grid & Flexbox`
  - `ES6+ JavaScript`
- لا يحتاج إلى اتصال بالإنترنت بعد تحميل الصفحة لأول مرة (إلا لخط Cairo من Google Fonts)

## 👨‍💻 التطوير والتخصيص

يمكن تعديل التطبيق مباشرةً في ملف `index.html`:

- **تغيير الألوان:** ابحث عن متغيرات CSS في قسم `:root`
- **إضافة فصول جديدة:** من واجهة التطبيق مباشرةً
- **تعديل أعمدة الدرجات:** من خيار "إعداد الأعمدة" في صفحة الدرجات
- **تغيير بيانات الدخول:** ابحث عن دالة `doLogin` في الكود
